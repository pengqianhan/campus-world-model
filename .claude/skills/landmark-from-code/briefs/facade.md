# Brief: facade agent

<!-- Sent as-is to the facade agent at the start of round 1 (Clock Tower, 2026-10-20), with local paths rewritten for `landmarks/clocktower/`. Model: the lead's (Claude Opus); agent type: general-purpose. -->

You are the **facade** agent on a small team building the University of Auckland Clock Tower in three.js from code alone, checked against Street View photographs. Project folder: `landmarks/clocktower/` in this repository; paths below are relative to it (do not commit — the lead commits). Other agents edit other files at the same time. **You own `src/parts/pavilion.js`, `src/parts/ranges.js` and `src/gothic.js` (the shared Gothic kit). Edit nothing else.**

**Read first:** `docs/CONTRACT.md` (frame, sizes, ownership, how to render and compare, budget, rules) and `docs/ART_BIBLE.md`. Then read `src/gothic.js`, `src/parts/pavilion.js`, `src/parts/ranges.js`, `src/parts/common.js` (sizes, read-only) and `src/clocktower.js`.

**`src/gothic.js` is shared**: the tower and centre agents import `Builder`, `addWall`, `addWindow`, `addPinnacle`, `addCourse`, `outline`, `worldUV` right now. Keep every exported function and its existing parameters working exactly (add new options with defaults, add new exports; never rename, remove or change what an existing call produces in a way that breaks it). Re-read the file before each edit. A broken gothic.js breaks everyone: after each change, render the whole building once to check that every part still builds (`part <name> failed` in the console means you broke something).

**Your job:**
1. **The two gabled pavilions** (left and right of the recessed centre) to read as the real ones from the front and from the oblique views along Princes St (`refs/streetview/*_wide.jpg`, 12 views; crop and zoom with PIL). Verify against the photographs: rock-faced ashlar fronts; plinth and string courses; three tall rectangular ground-floor windows of three lights with transoms; the upper group of pointed lancets under a large moulded hood; the slender shafts rising into the gable with small pinnacles; blind panels between floors; the gable coping, kneelers and finial; **the side walls** that the oblique views show (windows on them? buttresses? the depth of each pavilion); window reveals deep enough to cast shadow.
2. **Windows in the kit** (`addWindow`) look flat: real ones have light stone mullions and transoms, deep reveals, leaded/glazing bars, slightly varied dark reflective glass, and pointed heads with cusped tracery. Improve the kit so every window on the building (yours and other agents') gets better by default, keeping signatures compatible (e.g. new options `bars`, `cusps`, `hood`).
3. **The long ranges** either side behind the pavilions (`ranges.js`) are guesses: check their real position, height, roof and windows from the LiDAR and the photographs (they are mostly behind trees; get the massing and roofline right, details modest).

Measure, don't guess: LiDAR points in `data/clocktower_pts.npy` (x, y, z, class in local NZTM metres; class 6 = building; frame in `clocktower_frame.json`: tower centre `centre`, `axis` = −x of the view frame, `toStreet` = +z, ground 45.8 m); plan and elevation images `clocktower_plan_frame.png`, `clocktower_front_elevation.png` in `data/`. If a size in `common.js` looks wrong (pavilion x-extents, front z, eave 9.8, ridge 13.3), report it with numbers; use local constants meanwhile.

Work in rounds: change → `node tools/compare.mjs --out out/facade/rNN --match wide` → open the `*_strip.jpg` (reference | render | overlay) → compare closely → next change. Another agent refines the reference cameras (`views_refined.json` may appear and be used automatically) and the look agent changes materials and light — judge shape, not light.

Budget: pavilions + ranges ≤ ~120k triangles; keep `addWindow` cheap (it is called ~100 times). No Math.random. Do as many rounds as it keeps getting better (aim for 6–10). Finish with a short report: what you built, files, kit API changes (exact new options), triangles and build ms, paths of a before strip (`out/lead/baseline/`) and your best after strips, measurements, what still differs, what you'd do next.
